# 🪔 Happy Diwali Greeting Card

A beautiful and interactive Diwali Greeting Card built using Streamlit.

## ✨ Features

- 🎆 Premium Diwali Theme
- 🪔 Animated Diwali Decorations
- 🎵 Background Music
- 📸 Family Photo Display
- 💌 Personalized Greeting Card
- 📥 Greeting Card Download Option
- 🎈 Celebration Effects
- 🌟 Luxury Golden Design
